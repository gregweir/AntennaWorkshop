# Embedded Solver Decision

## Status

Keep NEC-2 export as the production path for now. A browser-based solver is technically feasible, but adding it would change the project’s distribution obligations and must be an explicit licensing decision.

## Verified Proof

On 2026-11-15, `nec2c-wasm` 0.1.3 accepted the exact 14.2 MHz free-space deck generated by Antenna Workshop and reproduced the native `nec2c` result of 67.513 − j33.263 Ω. The package exposes a 258,692-byte WebAssembly file with a 60,078-byte loader, or a 360,804-byte inline build. It does not require shared memory or special cross-origin headers.

This proves browser execution for one bounded reference. It does not establish accuracy for other geometries, grounds, sweeps, patterns, or installed antennas.

## Licensing Gate

The candidate engine is GPL-3.0-or-later; Antenna Workshop is MPL-2.0. Its licence, notices, corresponding source, pinned engine source, and reproducible build materials must remain available when the engine is distributed. Do not add the package until the project adopts and documents a reviewed compliance approach for the combined browser application.

## Required Implementation Boundary

If embedding is approved:

- load the solver only on request in a dedicated Web Worker;
- keep the WebAssembly asset outside the main JavaScript bundle and include it in offline caching;
- accept only decks generated by the bounded application exporter;
- cap deck size, wire and segment counts, frequency samples, memory, and execution time;
- treat solver warnings, malformed output, and unsupported cards as stopped results;
- show engine version, model inputs, convergence checks, assumptions, and limitations with every result; and
- begin with single-frequency input impedance only, not gain, pattern, field, exposure, or safe-power conclusions.

## Acceptance Tests

The browser result must match the native `nec2c` reference and remain within the documented cross-engine tolerance against PyNEC/NEC2++. Tests must cover worker cancellation, invalid decks, offline loading, service-worker upgrades, mobile memory limits, and preservation of the existing bundle budgets.

Source: [`nec2c-wasm` package documentation](https://www.npmjs.com/package/nec2c-wasm), version 0.1.3, reviewed 2026-11-15.
