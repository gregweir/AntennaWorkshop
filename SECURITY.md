# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [gweir@tartanleaf.com](mailto:gweir@tartanleaf.com). Include the affected version or commit, reproduction steps, expected impact, and any suggested mitigation.

Do not disclose an unresolved vulnerability in a public issue. Tartanleaf.com Inc. will acknowledge a report, investigate it, and coordinate disclosure when a fix is available.

## Supported version

The current `main` branch is the supported development version until tagged releases begin. Regulatory or calculation concerns that do not present a security risk may be reported through the public issue tracker.
