# RadioBook Antenna Workshop

[![Validate](https://github.com/gregweir/AntennaWorkshop/actions/workflows/validate.yml/badge.svg)](https://github.com/gregweir/AntennaWorkshop/actions/workflows/validate.yml)

RadioBook Antenna Workshop is an offline-first browser application for designing, understanding, building, tuning, and evaluating amateur-radio antennas. The working product direction combines construction calculators, live diagrams, educational guidance, feedline tools, and jurisdiction-specific RF exposure screening.

The current workshop includes dimensioned half-wave dipole, fan dipole, balanced-line multiband doublet, G5RV-family systems, phased wire collinear, inductively loaded dipole, trap dipole, small transmitting loop, inverted-V, EFHW, off-centre-fed dipole, J-pole, Slim Jim, Moxon rectangle, two-element cubical quad, three-element Yagi, inductively loaded vertical, ground-mounted quarter-wave vertical, elevated quarter-wave ground plane, and full-wave-loop designs. General wire-antenna guides cover support planning, equal-leg or perimeter construction, balanced feeding, common-mode control, installed measurement, and symmetrical tuning. The fan-dipole workflow calculates two to six independent resonant wire pairs, total material, and longest span while guiding stable spacing and interactive highest-frequency-first tuning without predicting mutual coupling or the combined feedpoint impedance. The doublet workflow sizes equal legs from the lowest intended frequency, shows balanced-line physical and electrical length plus an eighth-wave adjustment increment, and guides balanced tuner or external-balun commissioning without inventing the tuner-side impedance or loss. The G5RV-family workflow keeps classic, half-size, ZS6BKW, and custom radiator-and-matching-section systems distinct, converts cited electrical line references with an explicit velocity factor, and requires installed impedance, tuner, loss, common-mode, and per-band verification. Loaded-antenna workflows calculate an ideal single-band series reactance and inductance for a space-limited span or radiator, show base or elevated coil position graphically, and require installed tuning without claiming a physical coil design, match, bandwidth, efficiency, voltage, current, or heating prediction. The other multiband wire workflows include transformer assumptions, harmonic-use context, RF return-path or common-mode guidance, and applicable safety cautions. The EFHW workflow adds optional build-and-tune guidance and contextual explanations for impedance ratio, assumed end impedance, wire correction, and trim allowance without treating the calculator as a transformer design tool. The OCFD workflow likewise guides feedpoint selection, current-balun and choking decisions, unequal-leg trimming, installed measurement, and per-band verification without predicting the finished impedance or pattern. Vertical workflows distinguish a ground-level RF radial field from elevated sloping counterpoise wires and guide site planning, symmetrical construction, feed routing, installed tuning, and separate lightning and electrical-safety grounding. J-pole and Slim Jim guides explain construction-medium assumptions, parallel matching geometry, adjustable coax taps, choking, and controlled tuning; the Slim Jim workflow also covers its interrupted folded side and gap. Directional workflows guide constant-diameter Moxon construction, critical gap control, scale-faithful National Bureau of Standards Yagi geometry, feed and boom choices, and installed match and pattern verification without predicting finished performance. Feedline tools include guided first-order power budgeting for matched cable and accessory loss, SWR, return loss, mismatch loss, and accepted power; a velocity-factor-aware coaxial stub workflow with termination and calibrated trimming guidance; a lossless two-element L-network synthesizer that enumerates valid series/shunt solutions for a measured complex load; a single-section quarter-wave transformer planner for two real resistances with line-impedance, velocity-factor, and trim guidance; an ideal balun/unun ratio planner that compares adjacent integer winding options without pretending to design the magnetic component; and guided directional ERP/EIRP accounting with explicit power reference planes, documented loss, dBi or dBd gain references, and separate exposure duty-cycle transfer. Band selectors connect conventional metre names to their actual frequency allocations and wavelengths for Canada, the United States, the United Kingdom, and Australia.

An optional three-design comparison aid covers required space and supports, band intent, feed and tuning systems, directional context, construction complexity, and installed measurements for every antenna planner. It deliberately compares practical topology rather than ranking unmodelled gain, efficiency, signal strength, or site suitability; any compared design can be opened directly in the workbench.

Every valid antenna result can be printed as a focused build sheet containing the selected design, prioritized dimensions, installed-verification items, supporting calculations and assumptions, and the dimensioned drawing. Navigation, selectors, and unrelated workspaces are excluded from the print packet.

The two-band trap-dipole workflow solves matched ideal parallel-LC traps for two design frequencies and a constrained span, then shows component targets, trap placement, operating-frequency reactances, and the intermediate trap resonance graphically. Physical component construction, power rating, parasitics, loss, heating, matching, and installed performance remain explicit measurement and verification tasks.

Loaded dipole, loaded vertical, and trap-dipole results connect directly to a single-layer air-core coil construction planner. It converts the calculated inductance target into ideal and rounded turn counts, pitch, spacing, approximate winding-wire length, and a dimensioned coil drawing using the documented ARRL approximation. It detects wire that cannot fit in one layer and keeps Q, self-capacitance, self-resonance, voltage, current, heating, form loss, and weather effects outside the geometry estimate.

The trap-dipole workflow also includes an as-built commissioning worksheet for two finished traps. It records measured inductance, capacitance, assembled resonance, fixture details, conditions, and follow-up notes; compares each trap with the design target; separates component target windows from pair-matching thresholds; and graphs the two measured resonances against the target. Versioned records can be kept in browser storage, printed, or transferred through validated JSON import and export. The worksheet treats matching as construction consistency only and does not infer Q, uncertainty, power rating, loss, heating, insulation safety, or installed antenna performance.

The small-transmitting-loop workflow accepts a circular circumference, measured finished-loop inductance, equivalent parallel fixed or stray capacitance, and a real variable-capacitor range. It calculates ideal total and variable capacitance across a selected tuning range, checks whether the entered capacitor covers that range, and applies the ARRL under-one-sixteenth-wavelength diameter classification at the upper edge. It does not assume that distributed loop capacitance is always a valid lumped value, and deliberately does not estimate loop inductance, loss, efficiency, Q, bandwidth, circulating current, capacitor voltage, matching, pattern, exposure, or safe power.

The phased-wire-collinear workflow sizes two to eight equal corrected half-wave radiator sections and the shorted quarter-wave phase-reversing stubs between them. Radiator and stub trim allowances remain separate, and the phasing-line velocity factor affects only the stub’s physical one-way length. It identifies the documented odd/even balanced-feed class and historical impedance context without treating either as an installed result. The diagram and material totals support construction without choosing a feedpoint or claiming impedance, gain, beamwidth, sidelobes, bandwidth, loss, current, voltage, common-mode behaviour, or safe power.

The two-element cubical-quad workflow scales the ARRL full-wave driven-loop perimeter, a reflector five percent larger, diamond sides and spreader arms, and an explicit 0.10–0.25-wavelength boom spacing. Horizontal and vertical feedpoint context, independent trim allowance, total wire, and the forward direction are shown graphically. Spacing remains a modelling input rather than an optimization, and the workflow does not predict impedance, match, gain, beamwidth, front-to-back ratio, sidelobes, bandwidth, structural loading, exposure, or safe power.

The axial-mode helix workflow converts frequency, circumference ratio, pitch angle, turn count, and reflector diameter into helix diameter, turn spacing, axial length, and conductor requirements. It shows direct-endfire RHCP or LHCP winding context and separates exact construction geometry from classical NASA beamwidth, gain, resistance, and axial-ratio estimates. Those estimates are not measured performance; the complete reflector, feed transition, supports, and conductor geometry require modelling and verification.

The discone workflow converts the required lowest frequency into the sourced cone slant length and disc diameter, then derives cone height and base diameter from an explicit 25–40° half-angle. Separate disc and cone radial counts, cut lengths, total conductor, compact feed-gap guidance, and a perspective construction diagram support practical builds. It intentionally does not infer an upper cutoff, bandwidth, impedance, VSWR, gain, or installed pattern.

The log-periodic dipole-array workflow converts lower and upper operating edges, τ, σ, and an explicit active-region bandwidth factor into a complete element schedule. It calculates the rounded-up element count, full and half cut lengths, centre spacings, boom positions, apex angle, structural bandwidth, termination context, alternating boom connections, and forward direction. The planner keeps construction geometry separate from feeder impedance, matching, gain, pattern, and measured bandwidth.

The receive-only Beverage workflow converts a reference frequency, wavelength multiple, height, and true bearing into a surveyed straight-wire route, cut allowance, compass direction, and endpoint offsets. Terminated one-way and unterminated comparison modes keep the far-end configuration visible, while entered antenna-side and feedline impedances provide nominal transformer ratios without pretending to calculate soil-dependent surge impedance, gain, pattern, or front-to-back performance.

The compact receive workflow adds sourced Flag, point-fed Pennant, and EWE starting geometries. It keeps the feed-end primary-response and termination-end principal-null convention explicit, draws each topology, totals the required wire, and shows only nominal transformer ratios from entered impedance assumptions. The elevated Flag and Pennant remain distinct from the EWE's two ground returns; installed gain, pattern, null depth, and front-to-back performance remain modelling and measurement tasks.

The K9AY workflow plans two crossed quasi-delta loops on one support and shared ground. It maps a first true bearing into four selectable directions, identifies the active loop and whether feed and termination are reversed, draws the selected state, and totals wire for both loops. The published 25 ft by 15 ft geometry, 85 ft wire instruction, 390 Ω termination, and 9:1 impedance transformation remain transparent starting assumptions; controller design and installed directional performance are not inferred.

The Loop-on-Ground workflow plans a corner-fed square of insulated wire laid on the surface and isolated from earth and coax through a two-winding receive transformer. It converts the chosen broad low-angle receive axis into feedpoint orientation, totals wire and footprint, shows the source 5:2 transformer context, and warns before circumference reaches one wavelength. A comparison table distinguishes its site, direction, grounding, and switching needs from Flag/Pennant, EWE/Beverage, and K9AY families without ranking installed performance.

The untuned active receiving-loop workflow plans a circular one-turn vertical loop across an explicit receive range. It calculates conductor, area, mounting height, loop-plane orientation, and the expected bidirectional null axis, then checks both the 0.10-wavelength perimeter guidance and ARRL one-sixteenth-wavelength diameter classification at the upper edge. The balanced amplifier, power path, strong-signal performance, common-mode control, receiver protection, and transmit interlock remain documented selection and measurement tasks rather than inferred performance.

The receive-antenna selection wizard compares the Beverage, Flag/Pennant, EWE, K9AY, Loop-on-Ground, and untuned active-loop planners against explicit site and system constraints. It checks starting span, support height, surface-wire permission, antenna-circuit ground returns, active electronics, switching, and direction-control needs, then explains every fit, tradeoff, and conflict. It links directly to each planner without ranking predicted reception or replacing installed measurement.

The antenna picker supports two complementary paths. Guided mode asks for transmitting or receive-only use, then a site or operating goal, before presenting a small unranked set of relevant construction planners. Workbench mode preserves direct access to every design and adds text search plus Wire, Vertical, Directional, Loop, Broadband, and Receive-only category filters. Search and guidance change navigation only; they never alter the active calculation or hide advanced controls after a design is opened. Result cards across antenna, feedline, and regulatory workflows distinguish calculated values, published starting points, entered assumptions, and measurements that remain necessary on the finished installation. Antenna cards keep actionable build dimensions and measurement warnings visible while placing secondary context in a labelled disclosure.

The application is being developed locally before deployment at [radiobook.ca/antennas](https://www.radiobook.ca/antennas/). RadioBook Antenna Workshop is developed by Greg Weir, VA1GW, for [Tartanleaf.com Inc.](https://www.tartanleaf.com/).

The RF exposure workspace provides boundary-tested official power-density reference levels for Canada and the United States, a conservative single-source far-field estimate, frequency-normalized multiple-source aggregation, and a printable station project spanning independently positioned transmitting antennas and accessible evaluation points. Its interactive site plan supports drag, touch, and keyboard positioning while keeping the numeric coordinate fields synchronized for precise entry. Station sources can also record and visualize an unknown, omnidirectional, bidirectional, or directional azimuth envelope with true bearing and approximate beamwidth. Source-to-point analysis derives the true bearing, nearest entered lobe, off-axis angle, and illustrative envelope relationship for every path. These graphics and classifications are orientation aids only; the screen continues to apply maximum gain toward every point. Antenna geometry can be carried through ERP/EIRP system calculations into a station-project source without re-entering frequency, dimensions, power, loss, or gain. Station projects are saved only in the browser and can be exported as validated, versioned JSON files for backup or transfer. A structured evidence log preserves assumptions, measurements, source references, review dates, and reviewer notes in the portable and printable record. Each entry can be scoped to the project, a transmitter, an evaluation point, or a specific input. A derived review checklist distinguishes calculation blockers, category-level and field-level documentation gaps, recorded prerequisites, and independent technical review without assigning a compliance score. A project can be duplicated into an independent what-if scenario and compared with its saved baseline across every stable evaluation-point and evidence-entry identity. The comparison includes an input audit covering project state, source settings, point geometry, evidence, and added or removed entities. A read-only sensitivity explorer charts the complete multi-source total while varying transmitter output, duty cycle, antenna height, or one point’s radial plan distance. Users can set the displayed range, inspect every plotted sample in an accessible table, download the samples as CSV, and review interpolated crossings of the preliminary screening trigger. Separate United States workflows evaluate the FCC single-source and collective-source exemptions in 47 CFR § 1.1307(b)(3), while keeping exemption from routine evaluation distinct from compliance with RF exposure limits. United Kingdom workflows apply Ofcom's current assessment and record thresholds and reproduce the conservative v1.1 compliance-distance method with explicit antenna-size and reflection limitations. Australian workflows provide the ACMA class-licence gateway, ARPANSA RPS S-1 reference tables, and a versioned clauses 4–6 record worksheet. The worksheet distinguishes current named-standard and transitional assessment routes, captures reproducibility evidence, and includes a station-change log that keeps post-change clause 3 review, clause 4 assessment action, and declaration replacement separate. Its dedicated archival print report expands complete multiline content, change entries and documentation summaries without relying on form-control rendering. It never treats completed fields as a compliance determination. The tools expose average power, feed loss, antenna gain, antenna height, three-dimensional separation geometry, source inventory, and applicability assumptions. They do not determine compliance. Pattern-based attenuation, near-field evaluation, measurement uncertainty calculations, off-site source discovery, and automatic terrain or building modelling remain future work.

From the review checklist, a user can select a missing critical value and open an evidence draft already scoped to the matching project, source, evaluation point, and input. Reusable source-reference, measurement, conservative-assumption, and technical-review templates suggest record structure without supplying evidence values. Category-specific quality prompts record which reproducibility elements the author says are addressed and identify documentation follow-up without verifying the evidence. Evidence can be searched, filtered, sorted, summarized, and assigned an optional author-selected review reminder. Optional step-by-step guidance and touch-, keyboard-, and pointer-accessible contextual help explain unfamiliar workflow terms without hiding advanced controls. The station-project guide covers assessment context, a shared site origin, source inventory, accessible locations, evidence, applicability, and interpretation; field help clarifies duty cycle, maximum gain, antenna dimensions, and height references.
Reference-limit, single-source, and normalized multi-source guides now cover environment classification, regulatory averaging, accessible-point geometry, far-field applicability, source inventory, frequency-specific normalization, and escalation without turning a preliminary screen into a compliance result.

For the Australian workflow, gateway facts and model provenance can be carried into a new unsaved worksheet without filling assessment judgments, evidence, or the declaration. A separate ACMA simple RF exclusion-distance workflow reproduces the official public-exposure workbook above 30 MHz and adds the Amateur Class Licence far-field applicability check. Its maximum-gain, continuous-power result does not account for losses, environment, antenna pattern, multiple sources, or near fields.

The persistent header preferences include System, Light, and Dark display modes. System follows live operating-system colour-scheme changes.

The [RF exposure independent review package](docs/RF_EXPOSURE_REVIEW.md) identifies the exact implementation, governing sources, reproducible vectors, open technical decisions, and sign-off record required before public beta release.

## Local development

Requirements: a current Node.js release and npm.

```bash
npm install
npm run dev
```

The development server listens on all local interfaces. Open `http://localhost:5174/antennas/` on this computer or `http://192.168.8.x:5174/antennas/` from another device on the LAN, replacing `x` with the development computer's address.

LAN access over plain HTTP is suitable for browser testing, but service workers and installation require HTTPS or the device's own `localhost`.

## Verification

```bash
npm test
npm run test:e2e
npm run test:browser-matrix
npm run test:pwa
npm run build
npm run preview
```

- `npm test` runs calculation and data-contract tests.
- `npm run test:e2e` runs the exhaustive persistent-preference, interaction, update-notice, and responsive suite in Chromium.
- `npm run test:browser-matrix` runs focused release checks in desktop Chromium, Firefox, and WebKit plus representative Android and iPhone profiles. Install all three Playwright browser engines first; `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` may replace only the Chromium runtime.
- `npm run test:pwa` builds on the production preview to verify cold offline return across every workspace.
- `npm run build` performs strict type checking and creates the production PWA.
- `npm run preview` serves the production build on the LAN at port 4174.

See [`docs/BROWSER_TEST_MATRIX.md`](docs/BROWSER_TEST_MATRIX.md) for the automated coverage and the physical-device release checklist.

## Project layout

- `src/calculators/` contains pure, testable calculation functions.
- `src/components/` contains accessible interface and SVG visualization components.
- `src/regulations/` contains versioned jurisdiction metadata and source references.
- `src/styles/` contains RadioBook design tokens.
- `docs/` contains product, architecture, and regulatory-source documentation.
- `public/` contains installable-app assets.

Calculation results are planning and construction aids. RF exposure screening must identify its jurisdiction, assumptions, source revision, and limitations; it is not a substitute for measurements or professional assessment when a simplified method is inconclusive.
